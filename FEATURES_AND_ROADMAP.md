# Smart Launcher — функции и дальнейшее развитие

Актуально для версии **1.0.3 — «Расширенный поиск»**.

## Назначение

Smart Launcher — Windows-лаунчер сценариев. Режим объединяет приложения,
сайты, Steam-игры, файлы, папки, команды и проекты в одну упорядоченную
последовательность запуска.

## Реализовано

### Главная и навигация

- Приветствие с учётом времени суток.
- Адаптивные карточки режимов с индивидуальным цветом, иконкой и описанием.
- Запуск, остановка, редактирование, дублирование и удаление режима.
- Индикация уже запущенных приложений.
- Страницы «Главная», «Режимы», «Приложения» и «Настройки».
- PNG-иконки `Dashboard`, `Modes`, `Apps` и `Settings`.
- Сворачиваемая боковая панель с сохранением состояния.
- Плавные переходы, hover-состояния и поддержка светлой/тёмной темы.
- Настраиваемая прозрачность поверхностей.

### Редактор режимов

- Создание, редактирование, удаление и дублирование режимов.
- Название, описание, цвет и предварительный просмотр будущей карточки.
- Визуальный выпадающий список встроенных иконок Smart Launcher.
- Все иконки сценариев и приложений берутся только из `Assets`.
- Понятный список действий сверху вниз.
- Временное отключение действия.
- Изменение порядка, редактирование двойным щелчком и удаление.
- Для действия «Приложение» используется одно поисковое поле: совпадения
  по названию, категории и пути автоматически появляются в выпадающем
  списке с иконками.

### Поддерживаемые действия

- Приложение: EXE, ярлык, Chrome/Edge PWA или UWP/MSIX.
- Сайт: HTTP/HTTPS через системный браузер.
- Файл: открытие в назначенной Windows программе.
- Папка: открытие через Проводник.
- Steam: App ID или готовый `steam://` URL.
- Команда: выполнение через `cmd.exe`.
- Проект:
  - корневая папка;
  - открытие самой папки проекта;
  - несколько именованных наборов файлов;
  - включение/отключение отдельного набора;
  - множественный выбор файлов;
  - drag-and-drop файлов;
  - относительные пути для файлов внутри проекта;
  - абсолютные пути для внешних файлов.

### Запуск и остановка

- Настраиваемая задержка между действиями.
- Пропуск уже запущенных обычных приложений.
- Уведомления об успехах, пропусках и ошибках.
- Кнопка «Остановить режим».
- Smart Launcher хранит ID и время старта созданного процесса.
- При остановке завершаются только процессы, принадлежность которых
  лаунчеру удалось повторно подтвердить.
- Закрытие самого Smart Launcher не завершает запущенные сценарии.
- Полный текст импортированной команды показывается до первого запуска;
  выполнение требует явного подтверждения пользователя.

### Каталог приложений

- Сканирование известных путей, `App Paths`, реестра деинсталляции, PATH,
  меню «Пуск», рабочего стола, запущенных процессов и распространённых
  каталогов Program Files/AppData.
- Поиск всех обычных установленных приложений.
- Поддержка UWP/MSIX через `Get-StartApps`.
- Поиск Chrome и Edge PWA, включая `chrome_proxy.exe`/`msedge_proxy.exe`.
- Чтение библиотек Steam, Epic Games и GOG, а также игровых `.url`-ярлыков.
- Корректное чтение русских названий приложений.
- Поиск, фильтр по категориям и автоматическое определение категории.
- Статус, источник и полный путь запуска.
- Ручное исправление пути у найденной записи.
- Создание и удаление пользовательских записей.
- Стабильные иконки категорий из `Assets` после повторного сканирования.
- Защита от ложных записей, где реестр указывает на ICO вместо EXE.
- Автоматическая миграция старой схемы `apps.json`.

### Системная интеграция

- Системный трей с актуальной иконкой и быстрым запуском режимов.
- Единственный экземпляр приложения: повторный запуск активирует текущее окно.
- Обычное сворачивание оставляет окно на панели задач.
- Настройка `CloseToTray` управляет только кнопкой закрытия окна.
- Миграция старого JSON-ключа `MinimizeToTray`.
- Глобальная горячая клавиша `Ctrl+L` показывает и активирует лаунчер.
- Автозапуск вместе с Windows.
- Установщик создаёт ярлык на рабочем столе.
- В приложении остаётся кнопка восстановления ярлыка с актуальной иконкой.

### Данные и надёжность

Данные находятся в `%LOCALAPPDATA%\SmartLauncher`:

- `modes.json` — режимы;
- `settings.json` — настройки;
- `apps.json` — каталог;
- `Icons` — кэш иконок;
- `Logs` — журнал;
- `Backups` — пять последних резервных копий каждого JSON.

Реализованы:

- атомарная запись через проверенный временный файл;
- обычная `.bak` и ротация резервных копий;
- автоматическое чтение последней исправной копии при повреждении JSON;
- импорт и экспорт режимов;
- импортированные команды помечаются недоверенными;
- журнал запусков, пропусков, ошибок и системных событий;
- обработка необработанных UI, AppDomain и Task-ошибок;
- окно ошибки показывает путь к журналу.

### Архитектура

- Добавлены слои `ViewModels` и `Infrastructure`.
- Каталог, фильтры, список приложений, список режимов и поля редактора
  используют `INotifyPropertyChanged`, `ObservableCollection` и XAML binding.
- Сервисы отвечают за сканирование, запуск, хранение, обновления, логирование,
  горячую клавишу, трей и Windows-интеграцию.
- Code-behind оставлен координатором для нативных диалогов и Windows API;
  бизнес-состояние постепенно вынесено из окна.

### Обновления и распространение

- Основная версия — обычная self-contained установленная сборка без
  `single-file`; она быстрее запускается.
- Portable-вариант остаётся одним self-contained EXE.
- Подготовлен per-user установщик Inno Setup:
  - установка в `%LOCALAPPDATA%\Programs\Smart Launcher`;
  - меню «Пуск»;
  - опциональный ярлык рабочего стола;
  - опциональный автозапуск;
  - корректное обновление и удаление.
- Автообновление:
  - HTTPS JSON-манифест;
  - сравнение версий;
  - release notes;
  - загрузка с прогрессом;
  - обязательная SHA-256-проверка;
  - запуск подписанного установщика после подтверждения.

## Проверенное состояние версии 1.0.3

- Debug и Release собираются с `TreatWarningsAsErrors=true`.
- `dotnet run --project SmartLauncher.UI.csproj` запускает отвечающее окно.
- На тестовом профиле Windows найдено 181 приложение:
  - 51 UWP/MSIX;
  - 3 Chrome PWA;
  - обычные EXE и ярлыки меню «Пуск».
- YouTube обнаружен как Chrome PWA и используется действием
  «Приложение».
- Основная установленная публикация создана в `dist\installed-win-x64`.

## Что ещё стоит сделать

Для следующего релиза:

- выбрать реальный HTTPS-хостинг обновлений и задать URL манифеста;
- подписывать установщик сертификатом Authenticode;
- расширять набор тематических иконок в `Assets`;
- вынести оставшуюся навигационную координацию окна в команды ViewModel;
- добавить отдельный тестовый проект для сервисов хранения, миграций и запуска;
- добавить локализацию интерфейса, UI Automation-тесты и экран просмотра
  журнала внутри приложения.

Эти пункты не блокируют сборку 1.0; первые два требуют внешней
инфраструктуры релизов.
