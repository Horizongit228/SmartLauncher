# Smart Launcher 1.0 — полное описание

Релизная подпись: **«Самая первая версия»**.

## Концепция

Smart Launcher объединяет повседневные действия Windows в режимы. Вместо
ручного запуска редактора, браузера, мессенджера и файлов проекта
пользователь запускает одну подготовленную последовательность.

Режим хранит:

- название, описание, иконку и собственный цвет;
- упорядоченный список действий;
- состояние каждого действия;
- проектные наборы файлов;
- сведения, необходимые для безопасной остановки.

## Дизайн

Интерфейс построен как современная desktop-панель:

- собственная рамка окна и кнопки управления;
- тёмная и светлая темы;
- полупрозрачные поверхности;
- скруглённые панели, поля и карточки;
- единая сине-фиолетовая система акцентов;
- PNG-иконки навигации вместо эмодзи;
- адаптивные карточки режимов;
- hover- и pressed-состояния;
- плавные переходы между страницами;
- плавное открытие и закрытие бокового меню:
  - ширина изменяется с easing-анимацией;
  - подписи одновременно меняют прозрачность;
  - текст слегка сдвигается по горизонтали;
  - компактное состояние сохраняется между запусками.

В боковой панели отображаются версия `1.0` и подпись
«Самая первая версия».

## Главная

- приветствие с учётом времени суток;
- количество режимов и найденных приложений;
- карточки режимов с индивидуальными цветами;
- иконка, название, описание и состав сценария;
- статус готовности;
- количество уже запущенных приложений;
- запуск и остановка;
- редактирование, дублирование и удаление через контекстное меню.

## Редактор режимов

- создание и редактирование режима;
- предварительный просмотр карточки до сохранения;
- проверка цвета `#RRGGBB`;
- встроенные иконки Work, Gaming, Relax, Apps и Settings;
- иконки найденных приложений в выпадающем списке;
- выбор собственного PNG/JPG/ICO;
- извлечение иконки из EXE;
- упорядочивание действий кнопками вверх/вниз;
- временное отключение действия;
- редактирование двойным щелчком;
- понятные подсказки для каждого типа действия.

Для действия «Приложение» отображается не поле пути, а визуальный список
каталога с названием, категорией и иконкой.

## Типы действий

### Приложение

- обычный EXE;
- ярлык `.lnk`;
- UWP/MSIX через `shell:AppsFolder`;
- Chrome и Edge PWA;
- ручная пользовательская запись.

### Сайт

- проверка HTTP/HTTPS;
- запуск в системном браузере.

### Файл и папка

- проверка существования;
- открытие через назначенную Windows программу;
- открытие папки в Проводнике.

### Steam

- числовой App ID;
- готовая ссылка `steam://`.

### Команда

- выполнение через `cmd.exe`;
- полный текст импортированной команды показывается перед запуском;
- импортированная команда не считается доверенной без подтверждения.

### Проект

- корневая папка;
- открытие всей папки проекта;
- несколько именованных наборов файлов;
- отдельное включение каждого набора;
- множественный выбор;
- drag-and-drop;
- удаление и очистка файлов;
- относительные пути внутри проекта;
- абсолютные пути к внешним файлам.

## Каталог приложений

Источники поиска:

- стандартные и пользовательские папки программ;
- App Paths;
- реестр установленных приложений;
- меню «Пуск»;
- PATH;
- зарегистрированные команды;
- запущенные процессы;
- `Get-StartApps` для UWP/MSIX;
- ярлыки Chrome и Edge PWA.

В интерфейсе доступны только конкретные категории:

- Разработка;
- Игры;
- Браузеры;
- Общение;
- Мультимедиа;
- Работа;
- Другое.

Пункта «Все категории» нет. При открытии каталога выбирается категория
«Разработка», после чего пользователь переключается между конкретными
разделами.

Дополнительно реализованы поиск, повторное сканирование, источник и статус
записи, полный путь, ручное добавление EXE и удаление пользовательских
записей.

## Запуск и остановка

- действия выполняются сверху вниз;
- задержка настраивается от 0 до 5000 мс;
- уже работающие обычные приложения пропускаются;
- результат показывается в интерфейсе и уведомлении;
- лаунчер запоминает только созданные им процессы;
- перед остановкой повторно сверяются PID и время запуска;
- неизвестный или уже переиспользованный процесс не завершается;
- закрытие Smart Launcher не останавливает запущенные приложения.

## Windows-интеграция

- системный трей и быстрое меню режимов;
- единственный экземпляр приложения;
- повторный запуск активирует существующее окно;
- глобальная клавиша `Ctrl+L`;
- автозапуск с Windows;
- обычное сворачивание не скрывает кнопку с панели задач;
- `CloseToTray` применяется только при закрытии;
- кнопка восстановления ярлыка;
- создание основного ярлыка выполняет установщик.

## Надёжность данных

Каталог `%LOCALAPPDATA%\SmartLauncher` содержит:

- `modes.json`;
- `settings.json`;
- `apps.json`;
- `Icons`;
- `Logs`;
- `Backups`.

Сохранение выполняется через временный файл. JSON проверяется до замены
основного файла. Хранятся `.bak` и пять временных резервных копий. Если
основной JSON повреждён, приложение ищет последнюю исправную копию.

Необработанные UI, AppDomain и Task-ошибки записываются в журнал. Пользователь
получает понятное сообщение и путь к log-файлу.

## Архитектура

- .NET 8 и WPF;
- MVVM-состояние через `INotifyPropertyChanged` и
  `ObservableCollection`;
- отдельные ViewModels каталога и редактора;
- сервисы сканирования, запуска, данных, обновлений, логов и горячих клавиш;
- code-behind используется как координатор Windows API, трея и системных
  диалогов;
- атомарное JSON-хранилище отделено от UI.

## Распространение и обновления

Основной формат — установленная self-contained версия без single-file.
Portable-вариант остаётся одним EXE.

Inno Setup создаёт:

- установку в профиль пользователя;
- пункт меню «Пуск»;
- опциональный ярлык;
- опциональный автозапуск;
- запись удаления;
- корректное обновление существующей установки.

Автообновление использует:

1. стабильный HTTPS URL `releases/latest/download/update-manifest.json`;
2. сравнение версий;
3. загрузку установщика;
4. обязательную SHA-256-проверку;
5. подтверждение пользователя;
6. тихий запуск установщика.

| Статус | ранняя внутренняя сборка | первый полноценный релиз |
| Редактор приложения | ручной путь к EXE | список приложений с иконками |
| Иконка режима | текстовый путь/выбор файла | визуальный каталог и предпросмотр |
| Каталог | несколько известных программ | EXE, Start Menu, UWP/MSIX и PWA |
| Категории | общего разделения почти нет | семь конкретных категорий без «Все» |
| Пользовательские записи | только исправление пути | создание и удаление |
| Проекты | один список файлов | папка, drag-and-drop и несколько наборов |
| Боковое меню | простое изменение ширины | fade + slide + easing-анимация |
| Горячая клавиша | отсутствует | глобальная `Ctrl+L` |
| Трей | базовая реализация | single-instance и быстрый запуск режимов |
| Настройка закрытия | `MinimizeToTray` | корректная `CloseToTray` с миграцией |

| Ошибки | отдельные сообщения | централизованный журнал и global handlers |

| Остановка | могла опираться только на PID | PID + время старта и подтверждение владельца |
| Темы | преимущественно тёмная | светлая, тёмная и прозрачность |

| Обновления | отсутствуют | GitHub Releases, SHA-256 и release workflow |
| Архитектура | преимущественно code-behind | MVVM-состояние и сервисные слои |

## Ограничения первого релиза

- для публичного выпуска желательно подписать Setup.exe сертификатом
  Authenticode;
- индивидуальные иконки UWP пока могут заменяться общей иконкой категории;
- URL обновления можно окончательно зафиксировать после создания GitHub
  репозитория.
